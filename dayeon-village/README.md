# 모여봐요 다연마을 (안드로이드 태블릿용 영단어 앱)

초등 4~6학년 영단어 144개(12개 주제)를 다연이 얼굴과 함께 공부하는 집 전용 앱입니다. 매일 오늘의 단어 20개, 별 5개마다 알이 생기고, 친구 3명을 합쳐 큰 친구·집·나무·무지개·성으로 키우는 마을(낮·밤·계절 날씨, 하루 한 번 우체통 선물)이 있어요.

## APK 만드는 방법 (GitHub가 자동으로 빌드)

1. GitHub에서 **새 비공개(Private) 저장소**를 만듭니다. 예: `dayeon-words`
2. 이 폴더의 내용 전체를 저장소에 올립니다.
   - 웹에서 올릴 때: 저장소 → **Add file → Upload files** → 폴더 안의 파일·폴더를 모두 끌어다 놓기
   - `.github` 폴더는 숨김 폴더라 끌어다 놓기에서 빠질 수 있어요. 빠졌다면
     **Add file → Create new file** 에서 이름을 `.github/workflows/build-apk.yml` 로 적고,
     이 폴더의 같은 파일 내용을 붙여 넣어 저장하세요.
3. 올리면 **Actions** 탭에서 "APK 만들기"가 자동으로 돌아갑니다 (약 5분).
4. 끝나면 저장소 오른쪽 **Releases** 에 `dayeon-village.apk` 가 생깁니다.

## 태블릿에 설치

1. 태블릿 브라우저로 GitHub에 로그인 → 저장소 → Releases → `dayeon-village.apk` 내려받기
2. 파일을 열면 "출처를 알 수 없는 앱" 허용을 물어봐요 → 허용 → 설치
3. 홈 화면의 **다연마을** 아이콘으로 실행

## 업데이트할 때

`index.html`(app/src/main/assets)을 고쳐서 다시 올리면 새 APK가 만들어집니다.
**삭제하지 말고 그대로 덮어 설치**하면 별·기록·사진이 그대로 남아요.
(항상 같은 서명키 `app/dayeon.keystore`로 빌드되도록 해 두었어요. 이 파일은 지우지 마세요.)

## 기록 보관

- 별·기록·오답노트·사진은 태블릿 앱 저장소에 자동 저장돼요 (앱을 꺼도 남아요).
- 태블릿을 바꾸거나 앱을 지워야 할 때: ⚙️ 부모 메뉴 → **백업 저장** (다운로드 폴더) → 새 기기에서 **불러오기**

## 단어 바꾸기

`app/src/main/assets/index.html` 안의 `THEMES` 목록을 고치면 됩니다.
한 줄 형식: `['영어','뜻','그림 이모지','예문','예문 뜻']`
