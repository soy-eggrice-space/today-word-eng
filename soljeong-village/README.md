# 솔정마을 (다솔·다정이용 5살 한글·영어·수학 카드 앱)

집 안드로이드 태블릿 전용 앱입니다. 다연마을과 따로 설치되고, 두 앱이 함께 있어도 서로 기록이 섞이지 않아요.

## 들어 있는 것
- 처음 화면에서 다솔이 / 다정이 고르기, 언제든 "바꾸기"로 전환
- 한글 · 영어 · 수학 각 5문제, 카드 누르기만 (쓰기 없음)
- 과목마다 하루 한 번. 다 하면 "오늘 끝!"으로 잠기고 자정이 지나면 다시 열려요
- 단계(1~10, 5살 → 7살): 5번(5일) 연속 80% 이상 한 번에 맞히면 한 단계 올라가고, 한 판에서 많이 틀리면(5문제 중 2개 이하) 바로 한 단계 내려가요
  (1~3단계 5문제, 4~6단계 6문제, 7~10단계 7문제 · '한 번에 맞힌 비율' 기준)

| 단계 | 한글 | 영어 | 수학 |
|---|---|---|---|
| 1 | 그림 보고 낱말 고르기 (쉬운 2글자) | 듣고 그림 고르기 (3글자 낱말) | 5까지 세기·모양·많고 적음 |
| 2 | 그림→낱말, 낱말→그림 | 듣기 + 읽기 | 7까지, 그림 더하기 |
| 3 | 3글자 낱말, 카드 4장 | 4글자 낱말 | 10까지, 다음 숫자 |
| 4 | 3글자 낱말 ↔ 그림 | 알파벳 대문자 | 그림 빼기, 큰 수, 규칙 찾기 |
| 5 | 받침 있는 낱말 | 대문자 ↔ 소문자 (b d p q) | 모으기, 여러 규칙 |
| 6 | 비슷한 낱말 구별 (사과·사자·사탕) | 첫 글자 소리 | 숫자 덧셈·뺄셈 10까지, 가르기, 시계(몇 시) |
| 7 | 첫 글자 찾기 | 색깔·숫자 영어 | 10묶음 30까지, 15까지 계산 |
| 8 | 빈칸 글자 채우기 | 빠진 알파벳 | 20까지 계산, 몇 시 30분 |
| 9 | 문장 읽고 그림 고르기 | two cats 같은 말 읽기 | 50까지 10묶음, 뛰어 세기, 말로 하는 문제 |
| 10 | 그림 보고 문장 고르기 | The cat is sleeping. 문장 읽기 | □ 채우기 (4 + □ = 9), 섞어서 |
- 별 5개마다 알 → 친구 탄생, 친구 3명이 모이면 합쳐서 큰 친구·집·나무·무지개·성으로
- 📊 부모 리포트(처음 화면 오른쪽 위): 아이별 단계·지금 배우는 것·최근 정답률·연속 공부 일수·2주 달력·한 줄 요약
- ⚙️ 부모 메뉴(비밀번호): 아이 사진, 오늘 한 번 더 열기, 과목별 단계 −/＋, 별 조정, 백업

## APK 만들기
1. GitHub에 새 **Private** 저장소(예: `soljeong-village`)를 만들어요.
2. 이 폴더 안의 파일을 모두 올려요. 숨김 폴더 `.github` 도 꼭 함께 올려야 해요.
3. Actions 탭에서 "APK 만들기"가 초록 ✓가 되면, Releases 에 `soljeong-village.apk` 가 생겨요.
4. 태블릿에서 내려받아 설치해요. 업데이트할 때는 지우지 말고 덮어 설치해야 기록이 남아요.

## 목소리
태블릿 설정 → 텍스트 음성 변환 → 기본 엔진을 **Google** 로, 한국어 음성은 여성 목소리로 골라 주세요. 앱이 톤을 높여 밝게 읽어 줘요.
