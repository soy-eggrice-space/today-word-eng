단어키우기버전 0.1.18

설치 안내
두 가지 방법

단어를 공부하면 마을이 자라는 앱이에요. 웹앱으로 바로 열거나, 안드로이드 앱으로 설치할 수 있어요. 모든 기능을 그냥 쓸 수 있어요.

소개 영상

영상이 안 나오면 아래 링크로 열어 보세요
소개 페이지 열기

어느 쪽이 맞을까요?

웹앱아이폰과 아이패드, 컴퓨터. 설치 없이 바로 써 보고 싶을 때
안드로이드 앱안드로이드 폰과 태블릿에서 오래 쓸 때. 기록이 더 안전하게 남아요
1

웹앱으로 열기

웹앱 열기

아이폰 · 아이패드

  1. 사파리로 링크를 열어요
  2. 아래쪽 공유 단추를 눌러요
  3. '홈 화면에 추가'를 눌러요
  4. 홈 화면에 생긴 단어키우기를 눌러 시작해요

안드로이드

  1. 크롬으로 링크를 열어요
  2. 오른쪽 위 점 세 개 메뉴를 눌러요
  3. '홈 화면에 추가' 또는 '앱 설치'를 눌러요

컴퓨터

  1. 크롬이나 엣지로 링크를 열면 바로 쓸 수 있어요

한 번 열고 나면 인터넷이 없어도 열려요. 단어 읽어 주기는 기기에 들어 있는 영어 음성을 써요.

2

안드로이드 앱 설치

설치 파일 받기
  1. 안드로이드 폰이나 태블릿으로 QR을 찍거나 링크를 열어요
  2. 내려받은 파일(daneokiugi.apk)을 열어요
  3. '출처를 알 수 없는 앱 설치'를 묻는 창이 뜨면 '설정'으로 들어가 이번 한 번 허용해요
  4. '설치'를 누르고, 끝나면 '열기'를 눌러요

'Play 프로텍트' 안내가 뜨면 '세부정보 더보기'에서 '무시하고 설치'를 누르면 돼요. 스토어에 올리지 않은 앱이라 뜨는 안내예요.

처음 켜면

  1. '마을 만들기'를 눌러요
  2. 이름을 넣고, 마을(공룡 · 캐릭터 · 동물)과 단어장을 골라요
  3. '오늘 공부 시작하기'를 누르면 돼요. 마을과 도전은 처음 들어갈 때 안내가 나와요

알아 두세요

  • 공부 기록은 쓰는 기기에만 저장되고 밖으로 보내지 않아요
  • 웹앱과 안드로이드 앱, 다른 기기의 기록은 서로 이어지지 않아요
  • 웹앱은 브라우저의 방문 기록과 사이트 데이터를 지우면 기록도 지워져요
  • 새 버전이 나오면 같은 링크에서 다시 받아 덮어 설치하면 기록이 그대로 남아요. 웹앱은 다시 열면 알아서 바뀌어요
