단어키우기버전 0.1.13

단어를 공부하면,
마을이 자라요

영어 단어를 공부해서 받은 상자로 친구와 물건을 모으고, 나만의 마을을 키워요. 안드로이드 앱과 웹앱이 있고, 모든 기능을 그냥 쓸 수 있어요.

01

재미있게

  • 맞히면 별, 맞힌 문제가 모이면 알 상자와 물건 상자
  • 친구 셋을 합치면 쑥쑥 자라요
  • 하루 세 번, 단어를 맞혀 말썽꾸러기를 쫓아내는 도전
02

체계적으로

  • 초등부터 고등까지 4,200단어, 단어장 일곱 권
  • 단어 카드와 예문, 문제 유형 다섯 가지
  • 자주 틀린 단어는 오답노트로 더 많이 복습
03

아이가 먼저

  • 물건 셋을 조합하는 도감 50가지와 히든 조합 20가지
  • 아주 가끔 찾아오는 미스터리 친구
  • 공부할수록 늘어나는 칭호 36개

단어장 일곱 권

왕초보 200초등 저학년 500초등 고학년 500중학교 기본 1,000중학교 심화 500고등 기본 1,000고등 심화 500

공룡 마을, 캐릭터 마을, 동물 마을 가운데 하나를 골라 시작해요.

시작하기

웹앱으로 바로 열기

아이폰, 안드로이드, 태블릿, 컴퓨터 어디서나 열려요. 브라우저 메뉴에서 '홈 화면에 추가'를 누르면 앱처럼 쓸 수 있어요.

안드로이드 앱 내려받기
  1. 안드로이드 폰이나 태블릿에서 위 단추를 눌러요
  2. 내려받은 파일을 열고, '출처를 알 수 없는 앱 설치'를 한 번 허용해요
  3. 이름을 넣고 마을과 단어장을 고르면 시작이에요

알아 두세요

공부 기록은 쓰는 기기에만 저장되고 밖으로 보내지 않아요. 그래서 웹앱과 안드로이드 앱, 다른 기기의 기록은 서로 이어지지 않아요.

웹앱은 브라우저의 방문 기록과 사이트 데이터를 지우면 기록도 같이 지워져요. 오래 쓸 기기라면 안드로이드 앱이 더 안전해요. 새 버전은 같은 주소에서 다시 받아 덮어 설치하면 기록이 그대로 남아요.
